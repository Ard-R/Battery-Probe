Battery Probe

Monitor your Android device's battery performance.

Battery Probe is an Android application developed by Ardavan Rastkar to help users monitor battery performance while their devices are charging or discharging.

Features

- Monitor battery performance during charging and discharging.
- View battery temperature information.
- Configure temperature alarm thresholds.
- Receive alerts when temperature reaches configured warning levels.

Requirements

- Android 8.0 (API 26) or later.
- An Android device.

Installation

1. Open the Releases page.
2. Download the latest APK file.
3. Open the downloaded APK on your Android device.
4. If prompted, allow installation from this source.
5. Complete the installation and launch Battery Probe.
